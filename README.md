## Ejecución de la API FastAPI
Ir al Directorio del API
```sh
    Proyecto1_BI/Proyecto1.2_BI/api
```
### 1. Instalar Dependencias
```sh
    pip install -r requirements.txt
```

### Ejecutar la API con Uvicorn
```sh
    uvicorn main:app --reload
```

**Verifica la API en:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## Ejecución del Proyecto Angular

Ir al Directorio del Front
```sh
     Proyecto1_BI/Proyecto1.2_BI/app-web
```

### Instalar Dependencias
```sh
    npm install
    npm install papaparse
    npm install --save-dev @types/papaparse
```

### Ejecutar el Proyecto en Angular
```sh
    ng serve
```

 **La aplicación estará disponible en:** [http://localhost:4200](http://localhost:4200)
